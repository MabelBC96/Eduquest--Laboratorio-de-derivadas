# Eduquest – Laboratorio de derivadas

Aplicación educativa para grado undécimo.

## Módulos nuevos
- Explorador de secante y tangente con controles para función, punto y separación.
- Experiencia de realidad aumentada basada en A-Frame y AR.js con marcador Hiro. Requiere HTTPS, cámara y permiso del navegador.
- Misiones, puntos XP, insignias y progreso guardado localmente en el navegador.

## Publicación
GitHub Pages debe publicar desde la raíz de la rama `main`. El archivo de entrada es `index.html`.

## Uso de AR
Abre el laboratorio desde un dispositivo con cámara, inicia la experiencia y enfoca el marcador Hiro. Si AR no está disponible, el explorador gráfico continúa funcionando sin cámara.
